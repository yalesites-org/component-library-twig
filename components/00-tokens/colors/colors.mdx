# Colors

The YaleSites color system is built on a set of named tokens derived from Yale's brand palette. These tokens power the three-tier theme system — Global Theme, Section Theme, and Component Theme — giving sites flexibility while maintaining brand consistency and accessibility.

## How the Color System Works

Color in YaleSites flows from broad to narrow:

- **Global Theme (lever)** — Sets the site-wide color palette. Affects all color tokens throughout the site.
- **Section Theme** — Sets the background color of a page section. Scoped to one content region.
- **Component Theme (dial)** — Adds an accent color to an individual component, overriding section and global defaults for that component only.

For a deeper explanation of how these layers interact, see the [Theme System page](?path=/docs/introduction-theme-system--docs).
