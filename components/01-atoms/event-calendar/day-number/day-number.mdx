## Technical Specifications

- **Atomic Level**: Atom
- **Template**: `yds-day-number.twig`
- **Styles**: `_yds-day-number.scss`
- **Rules**: tokens only, no color props, states are props, the parent sets outer margin and width

### Accessibility

- The hidden label holds the full date, event count and any "today" or "selected" words. The visible number is `aria-hidden`.
- Today (white on Yale Blue) is 12.2:1. Selected (Yale Blue on Blue Soft) is 10.6:1.
