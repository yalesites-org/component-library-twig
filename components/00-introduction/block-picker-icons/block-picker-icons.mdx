# Block picker icons

Every block in the Layout Builder "Choose a block" panel has a small picture above its name. Editors scan those pictures before they read the names, so the picture has one job: show what makes that block different from the blocks next to it. This page is the reference for that set: the rules, the icons, and how we got here, so the next icon we add fits right in.

The icons are drawn at 501 x 261 and show up at about 125 to 150 px wide in the picker. Everything here is designed for the small size.

## The rules

1. **No real words.** Headings, labels, links and numbers are all bars. The block name already sits under the tile.
2. **One signature per block.** The thing that makes it that block (the play button on Video, the open panel on Accordion) is drawn large and in Yale Blue.
3. **Keep the blue small.** Yale Blue covers no more than about 25% of an icon, and most use well under 10%. No solid blue backgrounds. Every tile in a row should carry about the same weight.
4. **Heavy enough to survive the shrink.** Strokes are 6 px minimum and bars are 14 px minimum at full size. Structure and primary bars are Gray 500 or 600. Gray 300 is only for secondary body bars.
5. **Width tells contained from full width.** There is no page frame; the picker tile is the border. Contained blocks sit in the center column (x 130 to 371, or a similar inset). Full-width blocks run edge to edge.
6. **Images are a Gray 200 surface with mountains.** The mountains are Yale Blue only when the image is the block's signature (Image, Image Banner). Otherwise they're Gray 300.
7. **Links are a blue bar with a 6 px underline.** Link buttons carry a chevron.
8. **Check at 150 px, sharp and blurred.** Blur the set 1.5 px and make sure each icon is still identifiable next to its look-alikes.

## How we got here

The first draft read like documentation wireframes: real words in Yale New and Mallory, a faded page frame around every block, 4 px strokes, and a few blocks drawn as solid blue slabs. At picker size the words turned to noise and the blue blocks overpowered everything around them. Rev 2 replaced those rules with the ones above, and then we worked through the set block by block in Claude Design with comments on each icon.

### Where we explored directions

For four blocks the first redraw didn't say the right thing, so we drew several directions side by side and picked one.

**View.** View replaced the old listing blocks in the Views Rework and can show posts, events, pages, people or resources as a grid, a list or a condensed list. Any one layout would undersell it, so we went with what all of them share: content that's pulled in, searched and filtered, not placed by hand. The results run full width with the filter menu floating over them, so the filter doesn't look like it changes the layout.

### Smaller changes from review

- **Divider:** the rule became a thin line running past the text on both sides, so it doesn't read as one more text bar.
- **Facts and Figures, Quick Links, Callout:** redrawn as full-width banners on a Gray 200 background, which is how they actually render.
- **Facts and Figures:** two stats instead of three, so it isn't cramped.
- **Custom Cards:** cards got images back, with less text and no links.
- **Link Grid:** three columns with longer links instead of four stubby ones.
- **Spotlight - Portrait:** a 3:4 image instead of a very tall one.
- **Grand Hero:** the text panel is centered vertically.

## Adding a new icon

1. Start from the closest existing icon and the rules above.
2. Pick the one signature and make it blue. If you can't name the signature in a few words, the block probably needs a clearer job.
3. Check the blue budget and the weight next to its picker category.
4. Put it in its look-alike group at 150 px, sharp and blurred 1.5 px. If two icons could swap names, keep going.
5. Export at 501 x 261, named after the block in kebab-case (`office-hours.svg`).
