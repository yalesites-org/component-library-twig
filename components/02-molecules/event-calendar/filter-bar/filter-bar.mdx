# Filter bar

The Event Calendar filter bar: Search events, then Category, Audience and Event experience multi-selects. It is built from the Views block filter pieces (search input, Chosen multi-select with pills) and adds layout only.

Results update as visitors pick, so there is no Apply button. The parent sets outer margin and width.

### Filters

`filter_bar__filters` is a list of `{ id, label, options, selected, visible, open, show }`. `show: false` hides a filter. The empty-field text defaults to "Select options".

## Technical Specifications

- **Atomic Level**: Molecule
- **Template**: `yds-filter-bar.twig`
- **Styles**: `_yds-filter-bar.scss`
- **Reuses**: `@atoms/forms/views-filter/_yds-views-filter-form.twig`. No new input styles.
- **Rules**: tokens only, no color props, states are props, the parent sets outer margin and width

### Accessibility

- Each field keeps the Views block label and keyboard behavior. Tab order is Search, Category, Audience, Event experience.
- The stacked layout puts the label above each field.
