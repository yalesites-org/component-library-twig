# Text with Image (Content Spotlight)

The Text with Image component, also known as Content Spotlight, combines text content with an accompanying image to create visually engaging content blocks. This versatile component supports both landscape (3x2) and portrait (2x3) image formats and offers extensive customization options for layout, positioning, and visual styling.

## Theme Options

This component supports the following theme variations:

- **Default**: Standard theme using global color settings
- **One through Five**: Custom theme dials that override global settings with component-specific colors

Use the `text_with_image__theme` property to apply different themes. The theme affects the visual styling of the content block, including background colors, text colors, and link styles.

## Configuration Options

### Width Options

- **site**: Standard site width constrained to the main content area
- **highlight**: Full-width highlight section for maximum visual impact

### Image Position

- **image-left**: Image appears on the left side with text on the right
- **image-right**: Image appears on the right side with text on the left

### Image Style

- **inline**: Image aligns flush with the text content
- **offset**: Image is offset from the text content for a more dynamic layout

### Focus Options

- **equal**: Image and text receive equal visual weight in the layout
- **image**: Layout emphasizes the image more prominently

### Content Vertical Alignment

- **top**: Text content aligns to the top of the image
- **middle**: Text content centers vertically with the image
- **bottom**: Text content aligns to the bottom of the image

## Technical Specifications

- **Atomic Level**: Molecule
- **Template**: `yds-text-with-image.twig`
- **Styles**: `_yds-text-with-image.scss`
- **Variants**: Supports both landscape (3x2) and portrait (2x3) image formats

### Accessibility

- Uses semantic HTML structure with proper heading hierarchy
- Images include alt text support for screen readers
- Links are keyboard accessible and include focus indicators
- Sufficient color contrast ratios maintained across all theme variations
- Responsive design ensures content is accessible on all device sizes

### Behavior

- Responsive layout adapts to different screen sizes
- Image position may stack vertically on smaller screens
- Links include hover and focus states for better user feedback
- Supports both single and dual call-to-action links
- Image captions support HTML for enhanced formatting

## Usage Guidelines

### Best Practices

- Use high-quality images that support and enhance the text content
- Keep headings concise and descriptive (60 characters or less recommended)
- Use the overline sparingly for attribution or categorization
- Ensure text content is readable and not too lengthy (200-300 words recommended)
- Choose image position based on the focal point of your image
- Use the offset style to create visual interest and break up page monotony

### Things to Avoid

- Don't use low-resolution or poorly cropped images
- Avoid placing text-heavy images that compete with the written content
- Don't use too many content spotlight components consecutively
- Avoid using both links unless there are truly two distinct actions
- Don't rely solely on image captions for critical information
