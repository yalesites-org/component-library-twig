# Banner

The banner component displays hero-style content at the top of pages. It provides multiple variations to accommodate different content needs and visual presentations, from simple image banners to feature-rich action banners with multiple call-to-action buttons. Banners are designed to capture attention and provide clear entry points for users to engage with key content or actions.

## Variations

This component includes four distinct banner types, each optimized for different use cases:

### Action Banner

The most feature-rich banner variation, supporting text content, images, and up to two call-to-action buttons. Content can be positioned at the bottom, left, or right of the banner.

### Grand Hero Banner

A prominent hero banner designed for maximum impact, supporting full-width or contained content overlays with optional video backgrounds.

A streamlined banner focused on visual impact, displaying images with optional captions and minimal content overlay. Available in tall and short size variations.

## Theme Options

Banner variations that support theming (Action, Grand Hero, and Image banners) use the following theme variations:

- **Default**: Standard theme using global color settings
- **One through Five**: Custom theme dials that override global settings with component-specific colors

Use the `*__content__background` property to apply different themes. The theme affects the visual styling of the content area, including background colors and text colors for optimal contrast.

## Technical Specifications

- **Atomic Level**: Molecule
- **Action Banner Template**: `action/yds-action-banner.twig`
- **Grand Hero Template**: `grand-hero/yds-grand-hero.twig`
- **Image Banner Template**: `image/yds-image-banner.twig`
- **Video Banner Template**: `video/yds-video-banner.twig`
- **Styles**: `_yds-banner.scss`, `_yds-grand-hero.scss`, `_yds-image-banner.scss`, `_yds-video-banner.scss`
- **JavaScript**: Component-specific behavior as needed for video playback

### Accessibility

- Semantic HTML structure with proper heading hierarchy
- Background images implemented with appropriate alternative text handling
- Interactive elements (buttons, links) are keyboard accessible with clear focus indicators
- Sufficient color contrast ratios maintained across all theme variations
- Video content includes controls for play/pause and volume when applicable
- Content remains accessible when background images fail to load

### Behavior

- **Responsive Design**: Banners adapt to viewport size, with content repositioning for optimal mobile display
- **Content Layout**: Action Banner content position (bottom, left, right) adjusts based on viewport
- **Image Loading**: Uses responsive images with appropriate srcset for different screen sizes
- **Video Playback**: Video banners support autoplay with appropriate user controls
- **Theme Application**: Component themes override global color settings for visual variety

## Usage Guidelines

### Best Practices

- Use banners at the top of pages to immediately capture attention and set context
- Choose the appropriate banner variation based on your content needs:
  - **Action Banner** for pages requiring clear calls-to-action
  - **Grand Hero** for major landing pages or homepage
  - **Image Banner** for visual storytelling with minimal text
  - **Video Banner** for video-first content presentation
- Keep heading text concise and impactful (60 characters or less recommended)
- Limit snippet text to 1-2 sentences for readability
- Use high-quality images with appropriate aspect ratios (typically 16:9)
- Ensure sufficient contrast between text and background images
- Test banner content at different viewport sizes

### Things to Avoid

- Don't use multiple banners on a single page (reduces impact and creates visual clutter)
- Don't rely solely on background images to convey critical information
- Avoid lengthy text content in banners (use page body for detailed information)
- Don't use low-contrast color combinations that make text difficult to read
- Avoid autoplaying video with audio (creates accessibility and user experience issues)
- Don't use more than two call-to-action buttons in Action Banners

### Button Configuration Guidelines

For Action Banner buttons:

- **Mixed**: Primary button uses primary styling, secondary uses secondary styling (default, recommended)
- **Both Primary**: Both buttons use primary styling (use sparingly, can reduce visual hierarchy)
- **Both Secondary**: Both buttons use secondary styling (use for less prominent actions)
- **Alignment**: Consider your content layout when choosing button alignment (right-aligned works well with bottom layout)
