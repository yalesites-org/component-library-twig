Theming via CSS custom properties

Everything in this section sits inside .themed-scope, which sets a few custom properties on the light-DOM ancestor. Those values inherit into each shadow root and restyle the internals — no build, no per-component API. The divider turns red; the themed accordion accent turns orange.
